# generate_rowid_dataset — Подготовка данных для upsert

Набор скриптов для сбора, очистки и загрузки тестовых данных (row_id) для скрипта массового обновления строк (upsert) в платформе TOPS.

## Назначение

Подготовить корректный набор идентификаторов записей (`row_id`) из проекции TOPS для последующего использования в сценариях нагрузочного тестирования (upsert-операции).

## Порядок запуска

Выполнять строго последовательно, каждый следующий скрипт использует результат предыдущего:

### Шаг 1: Сбор `row_id`

```bash
cd tops_at
source .venv/bin/activate
python -m generate_rowid_dataset.download_rows_async
```

**Что делает:**
- Асинхронно (через `aiohttp`) запрашивает данные из проекции TOPS пачками по N записей
- Параллельность запросов ограничена семафором
- Сохраняет все `_id` в CSV-файл с колонкой `row_id`
- Выводит статистику по времени выполнения каждого запроса

**Основные параметры** (в блоке `if __name__ == "__main__"`):

| Параметр | Назначение |
|----------|-----------|
| `TOTAL_ROWS` | Общее количество строк для сбора |
| `BATCH_LIMIT` | Размер пачки (строк за 1 запрос) |
| `MAX_CONCURRENT` | Кол-во параллельных запросов |
| `OUTPUT_FILE` | Имя выходного CSV-файла в папке `data/` |

### Шаг 2: Очистка и перемешивание

```bash
python -m generate_rowid_dataset.shuffle
```

**Что делает:**
- Читает CSV, полученный на шаге 1
- Находит дублирующиеся `row_id`
- Интерактивно запрашивает подтверждение на удаление дубликатов
- Перемешивает записи случайным образом
- Сохраняет результат в новый CSV-файл

**Параметры** (в блоке `if __name__ == "__main__"`):

| Параметр | Назначение |
|----------|-----------|
| `INPUT_FILE` | Входной CSV из папки `data/` |
| `OUTPUT_FILE` | Выходной CSV с суффиксом `_shuffle` |
| `ROW_ID_INDEX` | Индекс колонки с row_id (0) |

### Шаг 3: Загрузка в БД Датапровайдера

```bash
python -m generate_rowid_dataset.upload_data_in_db
```

**Что делает:**
- Подключается к PostgreSQL Датапровайдера через `psycopg2`
- Загружает данные через быструю вставку `COPY FROM`
- Проверяет количество загруженных строк
- Выводит статистику по уникальности и дубликатам

**Параметры** (в блоке `if __name__ == "__main__"`):

| Параметр | Назначение |
|----------|-----------|
| `CSV_FILE` | Входной CSV (результат шага 2) |
| `TABLE_NAME` | Целевая таблица в БД |
| `DB_CONFIG` | Параметры подключения (берутся из `.env`) |

## Структура данных

```
data/
├── row_ids_YYYY-MM-DD_HH-MM-SS.csv         # Результат шага 1
├── row_ids_YYYY-MM-DD_HH-MM-SS_shuffle.csv # Результат шага 2
└── bkp/                                     # Резервные копии
```

## Зависимости

- `aiohttp` — асинхронные HTTP-запросы
- `psycopg2-binary` — подключение к PostgreSQL
- `tqdm` — прогресс-бар
